# Как получить APK «Семь чудес света»

## Вариант 1. Android Studio
1. Установите Android Studio с Android SDK 34.
2. Откройте папку `SevenWondersAndroid` как проект.
3. Дождитесь установки зависимостей и синхронизации Gradle.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл (если сборка прошла успешно): `app/build/outputs/apk/debug/app-debug.apk`.

## Вариант 2. GitHub Actions (без Android Studio)
1. Создайте новый GitHub-репозиторий и загрузите **содержимое** папки `SevenWondersAndroid` в корень репозитория, включая скрытую папку `.github`.
2. Перейдите в GitHub → **Actions** → **Build Android APK** → **Run workflow**.
3. После успешной сборки откройте выполненный workflow и скачайте артефакт `SevenWonders-debug-apk`.
4. Распакуйте артефакт и установите `app-debug.apk` на Android-устройство, разрешив установку из этого источника при необходимости.

Это отладочная APK-сборка, предназначенная для тестирования и установки вручную. Для публикации в Google Play требуется отдельная release-сборка с подписью.

**Примечание:** компиляция не была проверена в среде подготовки архива, так как отсутствовали Android SDK / Gradle и доступ к репозиториям зависимостей.
