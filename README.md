# Android-приложение «Семь классических чудес света»

Готовый нативный проект для Android на **Kotlin** и **Jetpack Compose** (Material 3).

## Как открыть в Android Studio
1. Распакуйте архив `SevenWondersAndroid-v2.zip`.
2. Откройте Android Studio -> **Open** -> выберите папку `SevenWondersAndroid`.
3. Дождитесь синхронизации Gradle.
4. Нажмите **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** для сборки установочного `.apk`.
